# Changelog

All notable changes to Triple Espresso are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - Unreleased

### Added

- Low battery option in Preferences: turn sleep prevention off automatically when running on battery power at or below a chosen level (5%, 10%, 15% or 20%). It is off by default, never applies while plugged in, and is hidden on Macs without a battery. Available in all 13 languages.
- Installer package: `scripts/build_pkg.sh` builds `TripleEspresso-<version>.pkg`, which installs the app to `/Applications`.
- GitHub Actions workflow that builds the installer package and attaches it to a GitHub Release when a version tag is pushed.

### Changed

- Renamed the app to Triple Espresso, with the bundle identifier `io.ir77.tripleespresso`.
- New espresso-cup menu bar icons (outlined when idle, filled with steam when active) and a new app icon. Both are generated by scripts in `scripts/`.
- Release builds target Apple Silicon (arm64) only.

### Fixed

- Sleep prevention now holds a single power assertion for as long as it is active, instead of recreating one every 10 seconds with an 8 second timeout. This closes a gap of roughly 2 seconds in every cycle during which the Mac was unprotected.

### Removed

- The auto-updater and the "Check for Updates" menu item. The previous update feed pointed at another project's releases.
- The unused DZFoundation dependency and the network entitlements.
